# Windows CVE PoCs in Rust

**Rust로 작성된 Windows 취약점 Proof-of-Concept(PoC) 모음**입니다.

이 저장소는 알려진 Windows 취약점을 Rust로 재현하고, 취약점 연구 및 분석을 위한 PoC 구현체를 제공합니다.

## CVE 목록

| CVE | 구현 언어 |
|---|---|
| CVE-2022-37969 | Rust |
| CVE-2024-49138 | Rust |
| CVE-2025-60719 | Rust |

## 프로젝트 목적

- Rust를 활용한 Windows 취약점 PoC 구현
- Windows 내부 구조 및 취약점 악용 원리 연구
- 보안 연구를 위한 참고용 구현체 제공
